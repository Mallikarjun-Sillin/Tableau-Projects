# Hospital Management Dashboard | Tableau

## Project Overview

This project focuses on analyzing hospital appointment data using Tableau. The dashboard provides insights into appointment status, patient visits, doctor workload, and reasons for hospital visits. The goal is to help hospital management monitor appointments and identify areas for improving operational efficiency.

## Objectives

* Track overall appointment activity.
* Monitor completed, scheduled, cancelled, and no-show appointments.
* Analyze appointment distribution by visit reason.
* Understand patient appointment patterns.
* Evaluate doctor appointment workloads.

## Tools Used

* Tableau Public
* Data Visualization
* Dashboard Design
* Data Analysis

## Dashboard Features

* Total Appointments KPI
* Completed Appointments KPI
* Cancelled Appointments KPI
* Scheduled Appointments KPI
* No-Show Appointments KPI
* Appointments by Reason for Visit
* Appointments per Patient Analysis
* Doctor Appointment Distribution
* Key Insights Section

## Key Insights

* A total of 200 appointments were recorded.
* No-show appointments were slightly higher than completed appointments.
* Checkups and consultations accounted for most hospital visits.
* Appointment cancellations may impact hospital scheduling efficiency.
* Monitoring appointment status can help improve patient attendance and resource planning.
